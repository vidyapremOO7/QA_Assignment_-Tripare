# UI Automation Playwright Tests

This repository contains Playwright tests for the provided test application.

## Structure
- `package.json` - project dependencies and test script
- `playwright.config.ts` - Playwright configuration
- `tsconfig.json` - TypeScript configuration
- `tests/` - all required test files

## Run tests
Install dependencies:

```bash
npm install
npx playwright install chromium
```

Run the full suite:

```bash
npx playwright test
```
